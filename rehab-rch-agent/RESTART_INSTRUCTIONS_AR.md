# شرح مفصل: كيفية إعادة تشغيل البوت

## الطريقة الأولى: استخدام لوحة المفاتيح (الأسهل)

### الخطوة 1: انقر على نافذة الترمينال
- انظر إلى الأسفل في VS Code حيث يظهر الترمينال (Terminal)
- انقر بالماوس داخل نافذة الترمينال السوداء

### الخطوة 2: اضغط Ctrl+C
- اضغط مع الاستمرار على زر `Ctrl` في لوحة المفاتيح
- بينما تضغط على Ctrl، اضغط على حرف `C`
- ستظهر رسالة مثل "^C" أو "Application stopped"

### الخطوة 3: انتظر حتى يتوقف البوت
- ستظهر رسالة توقف البوت
- سيظهر مؤشر الأوامر مرة أخرى (C:\Users\RCH-Rehab\Desktop>)

### الخطوة 4: شغل البوت من جديد
اكتب (أو انسخ والصق) هذا الأمر:
```
cd C:\Users\RCH-Rehab\physicaltherapy-assistance\rehab-rch-agent && .\venv\Scripts\python.exe bot.py
```
ثم اضغط Enter

---

## الطريقة الثانية: إغلاق الترمينال وفتح واحد جديد

### الخطوة 1: أغلق الترمينال الحالي
- انقر على علامة X بجانب "Terminal 1" في الأسفل
- أو اضغط على أيقونة سلة المهملات 🗑️

### الخطوة 2: افتح ترمينال جديد
- من القائمة العلوية: Terminal → New Terminal
- أو اضغط: Ctrl + Shift + `

### الخطوة 3: شغل البوت
اكتب هذا الأمر:
```
cd C:\Users\RCH-Rehab\physicaltherapy-assistance\rehab-rch-agent
.\venv\Scripts\python.exe bot.py
```

## ما الذي يجب أن تراه بعد إعادة التشغيل؟

### رسائل النجاح:
```
INFO | rehab-rch-agent | Starting Rehab RCH Agent v2
INFO | rehab-rch-agent | Staff source=env count=1 active=1
```
أو
```
INFO | rehab-rch-agent | Staff source=json count=1 active=1
```

**هذا يعني أن معرفك (7398495644) تم تفعيله!**

### إذا رأيت:
```
INFO | rehab-rch-agent | Staff source=none count=0 active=0
```
**هذا يعني أن البوت لم يقرأ الإعدادات الجديدة - جرب مرة أخرى**

## إذا واجهت مشاكل

### المشكلة: لا يتوقف البوت عند الضغط على Ctrl+C
**الحل:** أغلق نافذة الترمينال كاملة وافتح واحدة جديدة

### المشكلة: لا أجد نافذة الترمينال
**الحل:** اضغط Ctrl + ` (الزر فوق Tab) لإظهار/إخفاء الترمينال

### المشكلة: البوت يقول "Access denied" بعد إعادة التشغيل
**الحل:** تأكد أنك رأيت رسالة "Staff source=env count=1" عند بدء التشغيل

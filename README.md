## 🔍 Quick Reference Guide

### By Clinical Condition
- **Spinal Pain**: McKenzie Method, Maitland, Mulligan, Neurodynamics
- **Joint Dysfunction**: Mulligan MWM, Kaltenborn-Evjenth, Maitland
- **Soft Tissue Injuries**: Cyriax, Myofascial Release, Dry Needling
- **Neurological Conditions**: PNF, Motor Control, Neurological Rehabilitation
- **Sports Injuries**: Sports Rehabilitation, Functional Movement, Corrective Exercise
- **Chronic Pain**: Pain Neuroscience Education, Biopsychosocial Approach
- **Balance Disorders**: Vestibular Rehabilitation, Balance Training
- **Visceral Dysfunction**: Visceral Manipulation, Visceral Manual Therapy

### By Treatment Approach
- **Hands-On Manual Therapy**: Maitland, Kaltenborn, Cyriax, Myofascial Release
- **Movement-Based**: Mulligan MWM, McKenzie, PNF, Motor Control
- **Needling Techniques**: Dry Needling (Trigger Points & Fascial System)
- **Exercise-Based**: Therapeutic Exercise, Corrective Exercise, Motor Relearning
- **Education-Based**: Pain Neuroscience Education, Biopsychosocial Approach
- **Modality-Based**: ANF Therapy, Kinesiology Taping

## 📖 How to Use This Directory

1. **Browse by Category**: Navigate through the main categories above to explore related techniques
2. **Search by Condition**: Use the Quick Reference Guide to find techniques for specific conditions
3. **Cross-Reference**: Each technique page includes related techniques and integration strategies
4. **Evidence Base**: Each technique includes current evidence and research references
5. **Clinical Application**: Practical guidelines for implementation in clinical practice

## 🎯 Purpose and Scope

This directory serves as:
- A comprehensive reference for rehabilitation professionals
- An educational resource for students and practitioners
- A guide for evidence-based practice selection
- A framework for integrated treatment approaches
- A resource for continuing professional development

## 📝 Contributing

This is a living document that evolves with current evidence and practice. Each technique is documented with:
- Theoretical foundation and principles
- Clinical indications and contraindications
- Evidence-based applications
- Integration with other approaches
- Key references and resources

## 🌍 International Perspective

This directory recognizes that manual therapy and rehabilitation techniques are practiced globally with regional variations and cultural adaptations. The techniques included represent internationally recognized approaches with established training programs and evidence bases.

## ⚠️ Professional Use

These techniques should be applied by qualified healthcare professionals with appropriate training and certification. This directory is for educational and reference purposes and does not replace formal training or clinical judgment.

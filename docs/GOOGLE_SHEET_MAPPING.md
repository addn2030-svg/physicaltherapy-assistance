## How to Migrate Existing Data

1. Export your existing Clinical_Driver_Console sheet as CSV
2. Run converter:

```bash
python -c "
import csv, json
rows = list(csv.DictReader(open('Clinical_Driver_Console.csv')))
# maps to new template
for r in rows:
    out = {
        'patient_case': {
            'Patient_ID': r.get('Patient_ID'),
            'ChiefComplaint': r.get('Chief complaint')
        },
        'comparable_sign': {
            'CanonicalRegion': r.get('Canonical Region'),
            'MovementDirection': r.get('Movement Direction')
        }
    }
    print(json.dumps(out))
"
```

3. Or keep sheet as backup - report-generator skill exports CSV row matching original columns.

## Formula Replacement

Sheet formulas like:
```
=FILTER(Directional_Test_Registry!Directions, Region=SelectedRegion)
=VLOOKUP(Region+Direction+Position, Registry!... candidate muscles)
```

Are now:

```typescript
// lookup.ts
const regionData = registry.regions.find(r => r.canonical_region === selectedRegion);
const availableDirections = regionData.directions.map(d => d.direction);
const candidateMuscles = dirData.candidate_muscles; // direct lookup
```
